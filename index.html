quantum gate directory

    Groups

    Subgroups of the unitary group $\mathsf{U}(n)$ that are of particular importance. Every gate lives inside the unitary group; click a region to read about that subgroup.

    The small grey labels mark one example gate per intersection.


    SDK Support

    Wondering which framework implements a gate natively? The SDK support matrix shows every gate against Qiskit, PennyLane, Cirq, Q#, PyQuil, Braket, BQSKit, Qibo, pytket, Stim, and OpenQASM, with links into each SDK's documentation.
